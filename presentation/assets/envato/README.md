# Envato Elements assets (optional)

`design/build.mjs` looks here for licensed stock files and uses them only if present. The folder is git-ignored apart from this file, because an Elements licence covers the finished deck, not redistribution of the raw asset through a public repository.

| File | Used on | Treatment |
|---|---|---|
| `divider-texture.jpg` or `.png` | All six act dividers | Full-bleed, under a 55% charcoal veil (`1F2326`) so the type and progress strip keep their contrast |
| `act-I.jpg` … `act-VI.jpg` (or `.png`) | That act's divider only | Full-bleed photo under a 72% charcoal veil; overrides the texture on that divider |

Download from your own Elements account with a licence registered to this presentation, keep the licence certificate with the other project records outside the repository, and note the item name and author here:
